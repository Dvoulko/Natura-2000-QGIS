# Natura 2000 QGIS Mapping Project
### Protected Natural Zones Mapping using QGIS & Open Data

---

## 🇬🇧 English Version

### Description
Using **QGIS** software in combination with open-source spatial data, this project maps and delineates **Natura 2000** protected areas. This zoning is critical and must be strictly evaluated prior to the execution of any infrastructure project, such as photovoltaic (solar) parks, road network designs, or any other land-use activity. 

Natura 2000 is a European network of protected core breeding and resting sites for valuable and threatened species, aiming to ensure the long-term survival of Europe's most endangered species and habitats while promoting a harmonious coexistence between nature and human activities.

### Software & Tools
*   **GIS Software:** QGIS
*   **Data Sources:** Open-source environmental & spatial databases

## 🇬🇷 Ελληνική Έκδοση

### Περιγραφή
Χρησιμοποιώντας το πρόγραμμα **QGIS** σε συνδυασμό με ελεύθερα δεδομένα δημιούργησα ένα πρότζεκτ στο οποίο διαχωρίζονται οι περιοχές **Natura 2000**. Αυτή η οριοθέτηση είναι πολύ σημαντική και πρέπει να λαμβάνεται υπόψιν πριν την εκτέλεση οποιουδήποτε έργου, είτε είναι φωτοβολταϊκό πάρκο, είτε ο σχεδιασμός οδικού δικτύου ή οποιαδήποτε άλλη δραστηριότητα.

Οι περιοχές Natura 2000 είναι ένα ευρωπαϊκό δίκτυο προστατευόμενων φυσικών ζωνών που δημιουργήθηκε για τη διασφάλιση της επιβίωσης των πιο πολύτιμων και απειλούμενων ειδών και οικοτόπων της Ευρώπης, προωθώντας παράλληλα την αρμονική συνύπαρξη της φύσης με την ανθρώπινη δραστηριότητα.
